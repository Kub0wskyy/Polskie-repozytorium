# Polskie Repozytorium CloudStream

Zaktualizowany zestaw wtyczek dla CloudStream:
- **Filman.cc**
- **Ekino-tv.pl**
- **Zaluknij.cc**

### Konfiguracja:
1. Wgraj zawartość tego archiwum do swojego repozytorium na GitHubie.
2. W GitHub: `Settings` -> `Actions` -> `General` -> `Workflow permissions` ustaw na **Read and write permissions**.
3. Po uruchomieniu akcji, w CloudStream dodaj repozytorium:
   `https://raw.githubusercontent.com/<TWOJ_NICK>/<REPOZYTORIUM>/builds/repo.json`
4. Dane logowania możesz ustawić bezpośrednio w ustawieniach wtyczek w aplikacji.
